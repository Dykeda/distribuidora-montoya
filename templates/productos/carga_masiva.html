Carga masiva de productos

Útil para dar de alta muchos productos a la vez (por ejemplo, todo el catálogo Postobón inicial). Pega una línea por producto con este formato, separado por punto y coma:

nombre; categoria; unidades_por_caja; precio_venta_unidad; descuento_referencia

La categoría y el descuento de referencia pueden quedar vacíos (ej: Agua Cristal 600ml; ; 12; 2500 o Agua Cristal 600ml; ; 12; 2500; 5). El descuento de referencia es solo para autocompletar el % al registrar compras — se puede dejar en 0.
